# 历史案例命题关联门

本文件的受控案例规则约束历史案例解释与入库；用户临时样本按末节接入。两者不增加当前创作任务的命题要求。

只要主假设借用作品可见内容以外的信息，解释创意为什么与当前命题成立，就先核对同届次官方命题材料，并记录来源、能证明什么和不能证明什么。核对对象是主假设使用的任何外部命题事实，不设封闭关键词清单；包括但不限于命题身份、传播主题、任务、目标与核心信息，品牌定位、语气、角色、文化和视觉资产，目标受众、生活情境、痛点、需求与行为前提，产品或服务属性、成分、功效、用法、用量与包装机制，类别、赛道、提交规格、必用素材、授权与禁限要求，渠道、触点、活动、合作、预算、排期、转化与落地状态，以及专项奖或特别奖条件。官方命题材料能取得时，不得把主假设的核心关联以“仍待核验”留给人工评审；核验不到时，隔离该命题机制结论或降低案例学习范围，不让猜测进入运行包。

证据按以下顺序使用：

1. 同届次官方命题页或命题文件；
2. 同届次官方作品页中的原文与创意思想；
3. 其他届次的官方产品材料，只能辅助说明稳定产品属性，必须显式标为跨届支持，不能替代本届命题证据；
4. 说明书或专业依据，用于真实适用性、用法和用量。

官网精确命题页已经下线时，可以从该精确 URL 的可信时间戳网页存档恢复正文。登记前必须同时确认届次、命题单位、创作类别和页面编号；只登记存档正文实际出现的字段，缺失的交付规格、素材或限制继续标为未知。仅有同届官方新闻或解析文章时，可以用来定位页面和交叉核对，但不能单独替代精确命题页。

数字、半包和分隔线必须区分“包装允许的计量粒度”与“特定用户的真实用量”。例如，0.5袋分隔包装可以是命题要求传达的产品机制，但不表示每个儿童每次都应服0.5袋；实际用量只能由年龄、体重、说明书或专业指导确定。

“不能证明疗效、真实剂量或实际结果”是必要证据边界，不属于未完成核验。只有把创意机关为何与该命题或产品相关留成未知，才触发退回。

`form-and-structure-only` 记录只能解释正文、画面或页面中可直接观察的语言与结构。它可以确认官方作品页登记的品牌身份及作品中可见的品牌名、Logo或包装，但不能据此断言作品回应了命题目标、目标人群、产品卖点、品牌调性、必用资产或执行要求。出现这些判断时，要么补齐同届命题证据并升级证据范围，要么删除该适配结论并保持形式学习范围。

## 用户临时样本

用户上传的图片、文本及附带分析先分开处理：作品中实际可见的形式，用户对奖项/背景的陈述，以及有对应来源的已核验事实。来源不明时可按 `form-and-structure-only` 分析可见语言与结构，不自动进入受控案例库。缺图片或正文时只分析已提供内容，不编造观察。

首次可能让用户误以为奖项、命题适配或效果已验证时，简短说明当前学习范围；不每轮重复模板，也不为形式讨论强制索取链接。用户要求获奖背景、命题机制或效果研究时，再核对对应来源；奖级本身仍不能证明获奖原因或传播效果。将可用机制转译到当前任务，不复制原作句段或把其形式当用户已选文体。
