# 内容形态驱动与反卡片化设计门

本门适用于平面广告和营销策划。目标不是禁止矩形、表格或所有局部分组，而是阻止模型把网页 UI、仪表盘和圆角卡片当作无需理由的通用设计语言。

## 1. 默认规则

先判断内容之间是什么关系，再选择空间结构；不得先搭卡片网格，再把内容逐格填入。

以下做法默认不进入候选生产：

- 用重复圆角矩形、悬浮面板、玻璃拟态或阴影容器包裹几乎所有信息；
- 把平面广告做成网页首页、应用仪表盘、数据看板或功能入口集合，而创意本身并不讨论这些界面；
- 策划案跨页复用同一组卡片，只替换标题、图标和正文；
- 用卡片数量代替因果、层级、流程、空间、时间、对比或视觉动作；
- 用徽章、胶囊标签、小图标和装饰性留白掩盖内容不足；
- 把若干互不承重的信息盒命名为品牌屋、策略模型或执行闭环。

模型不得因为卡片整齐、易生成、易对齐或适合套模板就选择它。

## 2. 允许的局部例外

只有卡片本身具有可说明的内容语义或真实物件依据时，才可局部使用，例如：

- 方案正在展示真实的应用界面、社交帖子、票券、身份牌、商品卡或其他界面/物件样机；
- 离散且同级的少量项目确实需要逐项比较、选择或状态扫描；
- 局部容器能明确表达边界、归属或交互状态，去掉后会损害理解。

矩形照片框、表格单元格、必要文字底色、引文框和真实包装结构不因外形像卡片而自动失败。关键问题是容器是否承担内容关系，而不是是否有圆角。

使用例外时，后台至少记录：

- `semantic_role`：卡片具体表达什么关系或真实对象；
- `scope`：只出现在哪一页、哪一区域或哪一幅；
- `non_card_alternative`：无卡片方案是什么，为什么更差；
- `review_evidence`：缩略图、三秒观看或整页评审如何证明它没有退化为模板。

只写“更美观”“更整齐”“科技感”“方便排版”不构成例外理由。

## 3. 平面广告执行

方向和原型先用主体、动作、因果、尺度、空间、材质、留白与阅读顺序建立视觉判断。若去掉卡片边框后画面立刻失去全部结构，必须判断失去的是必要语义还是模板骨架。

没有真实界面/物件语义且主要构图依赖卡片网格、UI 面板或仪表盘外壳时，在高清生产前停止该方向并回到原型；不得靠换圆角、阴影、渐变或增加大图把同一骨架包装成海报。

## 4. 营销策划执行

页面结构随任务变化：数据使用合适的图表或表格，关系使用结构图，流程使用路径，空间使用平面或场景，时间使用节奏或甘特，预算使用可核算表格，关键视觉使用完整画面。不能把这些关系统一改写为卡片阵列。

五页样稿与整本评审都检查：每页是否由内容关系决定；例外卡片是否局部、必要且有记录；同一模板是否只是换文案。观察到全稿卡片化或卡片替代逻辑时，回到对应页面蓝图或内容原型重建，不进入内容通过。

## 5. 状态与回退

- 尚未观察到问题时，这是一项必须执行的设计约束和检查，不因历史案例的 anti-signal 自动删稿。
- 观察到无语义卡片骨架时，按质量门记录失败并回到最近的方向、原型或页面蓝图阶段。
- 例外理由和评审证据成立时，保留局部卡片，不做预防性清除。
- `direction-cards`、方法卡和案例卡是后台记录名称，不是前台使用卡片式排版的许可。
