# 当前作品、源与调用的一致性

多轮修改、系列延展或混合归档时读取本页。复用现有运行清单、series_plan和方向索引，不再建立一套审批。单一“当前”集合表示本次生效成员，每个成员指向准确版本的图片、原生源、实际主场景图、生成/编辑调用记录和预览；角色不适用时说明原因。实际路径与SHA-256是依据，目录名里的final/current/new不能决定选稿。

恢复先看用户最后认可与纠正，再读取当前集合。保存本轮确切成员数量、每幅利益角色及已认可关系；格式副本和预览不增加成员数。变更集合后同步根入口、短交接、展示页和preview别名；旧绑定稿及旧调用原样保留，不让旧别名覆盖当前事实。当前集合有冲突先修指向，不能随意挑一个“完成”目录。

## 原生源与调用

多轮同步优先使用[当前集合与事件工具](review-state-tools.md)的project生成新的清单快照、摘要和技术输入；不从文件夹名字或宽glob重选成员。快照入口最后提交，成功后显式使用其返回清单，旧入口保留为历史。

新生产及交付以[生产与当前交付入口](bound-production-and-current-delivery.md)为准：guard严格检查新请求，交付自动调用SVG检查，final_artifacts为唯一当前成员集合。下述可选字段兼容只用于旧记录读取，不能作为新分派豁免。

新请求使用已有`{path, sha256}`引用在`input_files`绑定依赖的本地生产脚本和输入；脚本原地修改会在下一次guard前检被阻断。用户限制品牌素材包时，在该生产请求的`asset_scope`保存`basis`（原始范围依据文件引用）、`allowed_assets`（允许原包文件引用数组）及`used_origins`（本次实际使用的原始品牌资产引用数组）；裁切/透明化等派生文件放`input_files`，来源链另留记录。路径均相对运行根，可在该根内保留原包的字节副本。前检核验文件与hash，并阻断不在允许集合的原始品牌资产。字段缺失的历史请求保持原口径；新受限请求须主动填写，不能以字段可选规避用户范围。外部事实文献与原创场景图不冒充品牌原包资产。

该检查不能识别未声明的输入、认证范围依据或自动追溯变换；执行者必须把真实输入完整列入并按原授权核验。范围扩大先依据已有明确授权或取得缺失授权，再另存请求；不能只改allowlist让机器通过。不会自动建立新的人工审核轮次。

PNG换了场景时核SVG主位图是否真换：选择实际主场景image节点，比较其解码字节SHA-256与本轮被使用的生成/编辑结果，再从该源真实回渲染。记录主位图对应的实际call/session与结果路径；宿主未暴露ID时按绑定入口记录可观测参数、原始返回和输出，不补造ID或复制上一版元信息。哈希一致只证明该图被嵌入，不能证明字版、裁切、整体导出或调用来源正确。

有多个image节点时不要用“任一图片hash匹配”代替主场景定位。主场景由真实合成结构确定；没有可靠节点ID可检查当前未绑定源并另存准确标识版本，不能为检查改写已绑定源。旧稿仅作只读检查，报告缺少定位信息即可。

对SVG可运行只读辅助工具（各路径按当前工作目录解释）：

```powershell
& "<workspace-python>" scripts/inspect_svg_source.py --source "<当前源.svg>" --root "<明确的依赖根>" --scene-id "<主场景image的ID>" --expected-scene-sha256 "<实际主场景图的SHA256>" --output "<新检查报告.json>"
```

不核主场景时省略最后两个scene参数，结果标为not-checked。工具检查源hash、可读取的原生文字候选、图片引用与嵌入字节、href/CSS url本地依赖；不联网、不修改图/源/字体，不覆盖旧报告。发现遗留“AI生成”等文字只列候选，不能自动删除；隐藏层、路径字和位图中文字、CSS可见性仍需人工查看实际渲染。报告退出0只表示检查顺利完成，不代表视觉验收或人审通过。

## 依赖与归档

依赖根可覆盖合法的兄弟字体目录，但必须是本次明确的项目/归档根；解析相对路径与符号链接后的绝对路径仍须位于根内。不自动放宽到整个磁盘，不读取外部URL补缺。每个实际本地依赖保留原相对结构并核字节hash；同目标路径不同hash时明确处理冲突，不能覆盖。工具报告不支持的引用时保持未核验，不把扫描没找到当作依赖完整。

归档复制后再核原件/副本hash、所需文件与依赖路径，实际检查图中文字，防止误选早期有标记版本。仅复制不会产生新的内容批准或提高源有效DPI；总览不代替全尺寸看图，也不追认未知审批元数据。保留失败选择记录，修正索引与副本，不重绘用户已认可作品。
