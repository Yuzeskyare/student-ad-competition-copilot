# 开放式视觉风格选择

用于平面广告与营销策划的方向、原型、生图和视觉复核。这里的风格包括图像与文字实际长什么样，不只是构图、隐喻或“想表达什么”。未指定风格不默认真实照片；专业、高质量、高保真不等于照片感。

## 开放选择，不建穷尽目录

用户明确指出艺术语言单一或机制失败后，下一轮按[反馈进入创作](feedback-to-creation.md)处理；不能把既有场景换配色/道具当成完成多样探索，也不因探索过多样艺术就破坏选定系列的共同美术。

风格名称、分类维度和组合方式持续变化且互相交叉。以下只是启发入口，没有列出的风格同样可以采用，不按列表排名，不做白名单、固定枚举、覆盖率或风格数量考核。允许混合风格，也允许不用现成名称而直接描述目标面貌。无须每次读取艺术史或搜索完所有风格才开始创作。

需要打开选择时，可从不同角度思考：表现媒介与工艺（如照片、漫画、手绘或版画）；造型与空间（如概括、夸张、平面或非现实空间）；艺术传统与文化语境（如特定地域、时代或亚文化）；审美组织（如极繁、极简、秩序或有意碰撞）；以及颜色、笔触、颗粒、材质、信息密度等可见特征。维度可增减、跨越或替换，不要求逐项填写。

例如，漫画内部可以是少年漫画、复古连环画或其他语言；插画可以是水彩、厚涂、线描或新的混合方式；极繁主义既可用插画也可用摄影拼贴实现。这些例子不是推荐顺序或默认候选，更不是完整分类。不要把所有漫画、所有插画归成一种面貌，也不要把极繁主义简单理解成堆满无关元素。

主要文字参与构图时，在方向和代表稿前读取[文字设计](typography-direction.md)。让传播语气、字形或字组特征与图像共同确定；系列维持共同语法，跨命题重新判断，不从上一任务继承默认标题。功能小字可保持中性，已有明确文字方向直接落实。

## 具体选择与可见特征

按任务取用下面的启发，不逐行检查或强行覆盖。名称只是定位，描述才说明本次想要的面貌；同名风格可以有不同处理。

| 选择入口 | 可以探索的语言 | 可写入本次视觉要求的特征示例 |
| --- | --- | --- |
| 摄影 | 纪实、棚拍、胶片、运动抓拍 | 真实光源、瞬间动作、材质与景深；只在摄影适用时写镜头要求 |
| 漫画 | 运动漫画、报刊漫画、复古连环画、实验漫画 | 墨线粗细、网点或平涂、夸张比例、动作线、分格节奏；不是一律大眼人物 |
| 绘画与插画 | 水彩、厚涂、炭笔、线描、编辑插画、绘本 | 透明色层和晕染、厚重笔触、擦拭颗粒、轮廓虚实；“编辑插画”还须具体到造型与着色 |
| 印刷与手工 | 木刻、丝网、孔版印刷、剪纸、刺绣、拼贴 | 刀痕、套色错位、纸层边缘、针脚、异材质拼接；工艺特征要适合图像用途 |
| 三维与材质 | 黏土、纸模型、低多边形、玩具、风格化三维 | 揉捏痕迹、纸折面、几何体块、表面粗糙度与比例；三维不等于写实 |
| 造型与空间 | 具象、概括、几何抽象、等距、扁平、超现实 | 轮廓简化、尺度反差、空间展开或非现实组合；主题仍可理解 |
| 审美组织 | 极繁、极简、装饰性、秩序、有意碰撞 | 重复与变奏、视觉重心、层叠和疏密；极繁可以使用摄影拼贴或插画 |
| 文化与时代 | 艺术装饰、波普、地域民间工艺、时代和亚文化语言 | 具体图形、用色、工艺和语境；不以地域名称替代研究，不套刻板符号 |

颜色、光暗、笔触、纹理、密度可以跨以上入口组合，也可增添其他有用维度。混合时说明主导语言及各部分如何结合，避免把互相冲突的风格词堆成一串。陌生表达按需查可靠来源或参考图，不必每次创作重读风格目录。

## 选择与成本

先读用户已指定或已批准的风格，明确命题、品牌、受众和图像任务。没有明确选择时，考虑有实质面貌差异的合理可能，选择能支持命题且有视觉吸引力的语言。推荐理由须说明为什么适合，不只说“高级”。写实仍是合法选择，但不能因为熟悉或易生成就自动胜出，也不能反向强制非写实。

同一创意可以比较不同风格，不把它们包装成新的创意方向。只有风格差异会影响效果、文字判断仍不足时，才生成少量有区分力的低成本对照；没有固定候选数、生成轮数或必须至少一张非写实稿的配额。已有选择直接沿用，比较和确认合并进既有方向/代表稿审核，不新增人工门。

## 将风格落实到提示词和画面

按实际需要描述线条、造型、颜色与明暗、纹理、空间、密度或其他关键特征，不只加一个风格名称。不必填满这些维度；选足以让生成器明确区分图片面貌的特征即可。叙事构图与视觉风格分别想清楚，两者共同进入提示词。

先形成与工具无关的视觉要求，再按[生图工具与宿主适配](image-tool-adaptation.md)转换为实际提示词、参考输入和可用设置。不要把某提供方的提示词写法当成全部生成器的规则。

下面是描述方法示范，均为编写示例而非已验证生图配方。使用时替换为真实命题，不照搬主题或配色：

| 任务与风格理由 | 从名称到可执行描述 | 偏离后修正重点 |
| --- | --- | --- |
| 校园运动主题以运动漫画加强动作表现 | 二维运动漫画；粗细变化墨线勾勒前冲人物，蓝白平涂、局部网点，速度线随主动作集中；夸张四肢有清楚关节关系 | 照片加网点不算成立；重述轮廓、色块明暗和夸张造型，避免只换滤镜 |
| 公益阅读主题以剪纸呈现“翻页打开世界” | 打开的书页延伸为层叠剪纸树冠；清楚剪切边缘、有限绿橙纸片、纸层浅阴影，树冠环抱阅读者 | 若变成真实树林，明确树叶和人物均由纸片形状构成；保留翻页关系 |
| 音乐活动以极繁拼贴传达参与热度 | 乐器剪影、票根和手绘节奏线形成高密度重复与变奏，围绕中心舞台展开，主标题区域清楚，材质接缝有意可见 | 若无焦点，修正尺度、明度与疏密层级，不自动删成极简；不添无关装饰 |
| 温和日常陪伴以水彩表达轻柔感 | 透明叠色、湿边晕染、可见纸纹，人物轮廓简化，暖赭与浅绿形成舒缓关系 | 若成为光滑三维，明确色层渗化和纸上平面笔触，不只追加“温柔” |
| 功能产品需要展示真实使用状态 | 自然摄影；说明使用动作、可辨认的产品结构和符合场景的光线，必要时给材质特写 | 保留摄影选择，修复不可信接触与产品错误；不为“多样性”改成漫画 |

风格为何适合是本次判断，不是“某类品牌只能选某风格”的映射。用户已有选择直接落实，无须为使用本表再选一遍。示例外的表达同样可以通过具体特征进入生成。

检查摄影惯用词是否与选定风格冲突。例如，在平面插画中无意追加摄影级真实、皮肤毛孔、镜头景深，可能把输出拉回照片。只有有意混合才保留，并说明哪些区域使用哪些语言。不要把任何词永久禁用：电影感、纹理或光照也可能服务于漫画、三维等风格。

首次结果按实际面貌复核：线条、色块、空间、纹理或密度是否体现所选风格？如果只是照片加滤镜、出现了一点漫画装饰或仅提示词名称正确，仍需修改关键描述或参考组织。不要用自动关键词命中声称风格成功，也不要无限抽卡；定位偏离特征后定向修正，必要时调整制作方式并说明实际限制。

生图前的简短方向说明应让人预期首稿的具体面貌与动作，而不是先生成默认写实图再附加模型滤镜。连续反馈指出同一融合或识别问题时，回查产品作用与视觉机制，不仅调整材质；用户已放弃的方向停止生产。此经验不推导为禁止摄影，摄影适合且已选择时继续使用。

风格成立与版面约束分别判断：纸片、针脚或木刻语言成立，不代表指定留白比例、补丁位置或动线也准确。文字空间与字组轮廓应在代表构图中确定，精确位置可按既定设计交给后续原生排版，必要的动线可用确定性绘制完成；先确认不会遮挡核心画面，不因这些局部偏离更换整套风格，也不把仍未满足的约束登记为通过。

## 品牌、图像任务与一致性

必须准确的Logo、包装文字、产品身份与明确命题限制继续遵守，但这些局部要求不决定背景、人物与空间都必须写实。可以在协调的非摄影画面中使用官方产品资产。不要因风格化擅改强制保真元素，也不要用资产白底等技术便利倒推整套风格。

平面以传播信息、品牌作用与视觉吸引力判断风格。策划案的主视觉、物料、空间示意、界面和图表按各自任务选语言；空间可理解不等于必须像实景照片。选定后维持可辨认的视觉系统，不为展示多样性每页换风格。

## 风格适用的质量判断

所有风格都须内容准确、关键信息可理解、画面完成并符合命题。摄影语言检查相应真实感；漫画、抽象或超现实表达检查造型意图、内部规则和可读性，不仅因比例夸张、空间非现实或缺少阴影就判错。极繁作品检查主次、节奏与关键信息可辨，不自动删成极简。现有反卡片规则针对用无语义容器替代内容关系，不是禁止繁复装饰或有组织的密集画面。

风格不是豁免：生成错字、错误品牌、无法理解的关系或无意的人体结构缺陷仍需修复。按问题范围修复并复核既定风格，不能把所有修正都引向摄影真实。记录沿用简短方向说明、提示词和已有视觉审核，不新增逐风格台账。
