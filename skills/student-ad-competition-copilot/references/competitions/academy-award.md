# 学院奖赛事配置

## 路由

- 赛事标识：`academy-award`
- 平面统一能力：`print-ad`
- 文案统一能力：`ad-copy`
- 营销策划统一能力：`marketing-plan`
- 原始类别：`平面类`、`文案类`、`策划类`
- 当前规则快照：2026秋季官方细则页（2026-09-09更新）
- 官方来源：https://www.5iidea.com/contents/32332
- 核对日期：2026-09-16
- 优先级：当季总细则 → 当季命题策略单 → 官方素材包 → 报名系统字段与校方要求

当前细则为已发布页面快照。遇到页面更新、具体命题或真实提交任务时仍须刷新；命题策略单的专项要求优先于通用细则。

## 策划类规则快照

| 字段 | 值 |
| --- | --- |
| 内容 | 按命题策略单创作；突出核心创意、逻辑、传播与落地 |
| 页面 | A4横竖均可；每页一张JPG，300dpi、RGB、单张20MB以内 |
| 页数 | 正文与附录合计10–30页；封面、封底、目录不计 |
| 数据 | 引用数据必须注明出处 |
| 外部素材 | 图片或照片需注明示意用途并取得授权确认 |
| 上传字段 | 摘要、核心主张、目标人群、核心传播场景与媒介、创意亮点 |

总细则不要求策划案机械包含调研、市场分析、媒介投放和费用预算等全部模块。具体命题未要求的模块不得成为阻塞项；出现外部数据、预算或KPI时仍须满足证据、算术和测量定义契约。执行时读取`references/deliverables/marketing-plan.md`与`references/competitions/marketing-plan-profiles.json`。

## 文案类规则快照

| 字段 | 值 |
| --- | --- |
| 结构 | 一句品牌Slogan作为总标题；正文按命题策略单创作 |
| 纯文案 | 系统直接输入，不插入图片或表格，无需命题Logo |
| 图文类 | 独立记为`graphic-copy`，不进入纯文字路径 |
| 子类型与长度 | 必须由具体命题策略单确认 |

执行时读取`references/deliverables/ad-copy.md`与`references/competitions/ad-copy-profiles.json`并建立命题约束JSON。缺少命题级子类型或长度时返回`needs_brief_constraint`，不得拿总细则能力上限代替。

## 平面类规则快照

| 字段 | 值 |
| --- | --- |
| 画布 | A3（297×420mm），横竖均可 |
| 在线文件 | JPG、PNG或GIF |
| 色彩模式 | RGB |
| 分辨率 | 不低于120dpi |
| 单文件大小 | 不超过20MB |
| 系列数量 | 不超过3幅 |
| 源文件 | 平面作品须按当前细则上传网盘链接 |

## AIGC 与权利记录

所有作品按实际情况声明原创素材、非原创素材和AI工具使用情况。只有`aigc_used=yes`时才要求记录工具名称、关键交互、使用环节、介入程度、代表性初始素材或过程文件，以及人工策略、选择、排版、合成、修改和最终定稿过程；`no`时不要求空白AIGC记录，`unknown`必须在交付前解决。字体和外部素材仍须完成授权与来源检查。

## 命题级覆盖

每个命题单独解析品牌、产品、主题、人群、传播任务、允许类别、必备广告语或资产、允许声称、限定说明、敏感对象和授权边界。不能把命题页的建议数量直接覆盖总细则的系列上限；无法确认时选择同时满足两者的范围并记录判断。

## 平面生产与 QA 增量

1. 验证A3、RGB、格式、分辨率、文件大小与系列数量。
2. 对生成底图执行伪文字、伪Logo、敏感或受保护对象检查。
3. 产品、Logo、标题、数字和限定说明使用确定性合成并保存源文件哈希。
4. 使用生成式AI时整理可追溯证据链；未使用时只保留`no`声明。
5. 系列共享核心机制，并通过不同场景、空间或叙事提供信息增量；同背景只换文案属于可观察失败。
6. 可读性修复按单幅局部冲突处理，不机械复制到全系列。

## 完成状态

`method_validated`只表示共享方法在声明范围内走通。`submission_ready`必须在真实参赛时完成当前细则、截止日期、命题素材、报名字段、权利、AI材料、最终文件、真实上传和回执复核。
