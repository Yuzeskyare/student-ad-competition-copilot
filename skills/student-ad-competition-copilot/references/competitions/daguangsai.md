# 大广赛赛事配置

## 路由

- 赛事标识：`daguangsai`
- 平面统一能力：`print-ad`
- 文案统一能力：`ad-copy`
- 营销策划统一能力：`marketing-plan`
- 原始类别：`Aa 平面广告`、`F 策划案类`、`G 文案类`
- 当前规则快照：第18届（2026）
- 官方来源：https://www.sun-ada.net/about_intrs2.html
- 优先级：当届参赛指南 → 当届命题页与策略单 → 官方素材包 → 学校或赛区补充要求

遇到新届次或真实提交任务时先刷新规则快照。赛事通用规则给出能力上限，具体命题可以缩小范围，不能静默扩大。

## 策划案规则快照

| 字段 | 值 |
| --- | --- |
| 原始类别 | F 策划案类 |
| 页面 | 16:9或A4，横竖均可 |
| 正文 | 最多30页；封面、正文内容、封底均计入 |
| 附件 | 最多10页 |
| 在线文件 | 单个PDF，不超过100MB |
| 内容要求 | 优先按命题策略单；未给侧重时围绕洞察、策略推导、创意呈现和落地实施 |
| 现场决赛 | 全国一等奖通过现场提案产生；不属于常规创作运行完成条件 |

执行时读取`references/deliverables/marketing-plan.md`与`references/competitions/marketing-plan-profiles.json`。页面角色必须由交付清单明示；命题未要求预算、KPI或调研时不阻塞，明确要求时才形成对应内容门。

## 文案规则快照

| 字段 | 值 |
| --- | --- |
| 原始类别 | G 文案类 |
| 允许子类型 | `long-copy`、`seeding-copy` |
| 长度 | 100–500字，含标点 |
| 作品形态 | 纯文字；无命题Logo、图片、表情或其他形式文件 |
| 身份信息 | 不得出现创作者姓名、院校、院系等特殊标记 |

执行时读取`references/deliverables/ad-copy.md`与`references/competitions/ad-copy-profiles.json`，并建立命题约束JSON。命题可以缩小子类型或长度范围，不能扩展赛事白名单。

## 平面规则快照

| 字段 | 值 |
| --- | --- |
| 画布 | A3（297×420 mm），横竖不限 |
| 色彩模式 | RGB |
| 分辨率 | 300 dpi |
| 在线文件 | JPG |
| 单文件大小 | 不超过5MB |
| 系列数量 | 单幅或系列；系列不超过3幅 |
| AIGC | 使用时在报名表相应位置注明并保留记录；未使用时不要求记录 |

## 命题级覆盖

每个命题建立独立`brief-evidence.md`，覆盖当届主题、目标人群、允许类别、企业或产品必备信息、资产边界、允许声称、限定说明、禁止内容及版本差异。不得把一个命题的企业特别奖、产品卖点或禁区迁移到另一个命题；命题方推广措辞不自动等于可独立验证的产品事实。

## 平面生产与 QA 增量

1. 验证像素尺寸与300dpi元数据；A3竖版参考像素为3508×4961。
2. 验证每个JPG小于5MB、RGB、系列不超过3幅。
3. 检查命题主题和强制项使用当届版本，旧年度主题不得残留。
4. 对包装、Logo和产品源文件记录哈希，确保合成过程没有重画或变形。
5. 健康、药品、两性或医疗相关命题增加绝对化声称、误导性保证、低俗暗示与危险行为检查。
6. `aigc_used=yes`时保存工具名称、关键交互、生成层、人工合成与修改说明；`no`时不生成空白记录；`unknown`必须在交付前解决。

## 完成状态

`method_validated`只表示共享方法在声明范围内走通。`submission_ready`必须在真实参赛时完成当届规则、命题素材、校方要求、上传字段、最终文件、权利检查和上传回执复核；作品编号、提交截图与回执只能在实际上传后记录。
